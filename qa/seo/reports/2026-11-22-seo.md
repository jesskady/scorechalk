# SEO and discoverability audit: 2026-11-22

This is the first run. Every suggestion is new. **Limits this run:** scorechalk.com was unreachable from the cloud sandbox because the network policy blocks the host, and the PageSpeed Insights API was rate-limited (HTTP 429). So this audit reviews the source in `public/` and `worker/` only. To include the live site next time, add `scorechalk.com` to the environment's allowed domains.

## 1. Top 3 this week

1. **SEO-004: Set up Search Console (domain property) and Bing Webmaster, and submit the sitemap.** Without them, nobody can see which queries and pages work. It takes about 10 minutes through a Cloudflare DNS TXT record.
2. **SEO-001 + SEO-002: Add canonicals everywhere and noindex shared-game links.** Every `?s=<token>` share is a fresh crawlable URL with players' names in the title. Add an `X-Robots-Tag: noindex` header in the Worker's existing share-preview branch, and self-canonicals on the home and app pages.
3. **SEO-003: Give the home page a real title and description.** "Score Chalk" alone matches no searches. Name the games in both.

## 5. Health snapshot (from source; live not verified)

- **PageSpeed mobile:** not measured (PSI 429, quota exhausted).
- **robots.txt:** fine. It disallows `/api/`, `/auth/`, `/account/`, `/admin/` and points to the sitemap.
- **sitemap.xml:** 15 URLs. All public pages are there except `/tournament/`. There is no `lastmod`, and the private pages are correctly left out.
- **Structured data:** The 7 landing pages have WebApplication + FAQPage, and the JSON-LD looks valid in source. FAQ rich results aren't shown for sites like this since 2023, so the FAQ markup is harmless but brings no rich snippets. The home page has no structured data.
- **Canonicals:** present only on the 7 landing pages.
- **Social:** Every main page has og:image and twitter:card. Canasta, Farkle and score-keeper reuse builder.png. Tournament has no og:image, and privacy and terms have no OG tags.

## 6. Research covered this run

- **Canonical vs noindex for parameter URLs** (Google Search Central): use canonical for duplicates and noindex for pages that shouldn't be indexed, never both. Led to SEO-001 and SEO-002.
- **IndexNow via Cloudflare Crawler Hints**: one click, triggered by cache misses, checkable in Bing Webmaster. Led to SEO-005.
- **Competitor scorekeeper apps**: Spades, Hearts, Phase 10, Five Crowns and Rummy recur as headline games. Led to SEO-011 and SEO-012.
- **Manifest screenshots / Richer Install UI** (web.dev): needs at least one screenshot per form factor, PNG/JPEG, 320–3840px. Led to SEO-009.
