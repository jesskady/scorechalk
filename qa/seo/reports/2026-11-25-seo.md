## Part 1: Technical

### Top 3

1. **SEO-004: Verify Search Console (DNS domain property) and Bing Webmaster, and submit the sitemap** (High, S). Ten technical fixes went live today. Search Console's Page indexing report is the only place to see whether the http/www duplicates drop out and the `?s=` links stay out. ### New since last run

- **SEO-034: Honest sitemap lastmod.** The live sitemap is a day behind git. Google's docs say lastmod should only move for significant changes (main content, structured data, links), and if the dates are inaccurate it may ignore them. A header or badge commit shouldn't re-date every page. Impact Low, effort S.
