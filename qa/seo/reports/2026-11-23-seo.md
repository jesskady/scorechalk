Run 3. The live site was checked (all public pages return 200). There have been no site changes since the last run (main is still at 00c063b), so every older suggestion is still open. 4 new suggestions, 22 pending, 0 done.

## 1. Top 3 this week

1. **SEO-016: Force HTTPS and send HSTS** (High, S). `http://scorechalk.com/` still serves the full site with 200 and no redirect, which makes a duplicate copy of every page. To fix it, turn on Cloudflare "Always Use HTTPS" and HSTS, and set `url.protocol = 'https:'` in the www redirect in `worker/index.js`.
2. **SEO-003 + SEO-002 + SEO-007: Fix the home page head in one edit** (High, S). The title is just "Score Chalk", there's no canonical or og:url, and there's no WebSite/Organization JSON-LD. Do this in one pass on `public/index.html`, and add canonicals to the five app pages, `/tournament/`, `/privacy/` and `/terms/`.
3. **SEO-021: Holiday game-night pages** (Med, M, time-sensitive). Skyjo, Oh Hell and UNO scoring guides plus a `/game-night-score-keeper/` hub. With about 4 weeks to Christmas, this only pays off if it ships this week. If you start one thing in Search Console (SEO-004), do it at the same time so you can see whether the pages get impressions.

## 6. Research covered this run

- **Image SEO for an image-less site:** alt text and surrounding content drive Google Images, and schema `image`/og:image are preferred-image hints. The site has no `<img>` at all, which led to SEO-023.
- **Phase 10 / printable sheets:** paid single-game apps exist, and "printable" templates (many spammy) dominate the results. This led to SEO-024 and strengthened SEO-011.
- **MTG / Commander roundups:** the Draftsim roundups (Feb and Aug 2026) list native apps only, and EDHREC has no tools directory. This led to SEO-025.
- **Darts communities / launch venues:** couldn't get the r/Darts self-promotion rules (no Reddit results), but Product Hunt hosts darts-scorer launches. This led to SEO-026.
- Limits: developers.google.com and draftsim.com aren't in the sandbox's allowed domains, so they were read from search summaries only.
